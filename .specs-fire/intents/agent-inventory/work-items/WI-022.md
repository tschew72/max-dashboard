# WI-022: Agent Detail Filter (Click-to-Filter)

## Description
When clicking an agent card from WI-021, filter the existing cron job runs and session views below to show only that agent's data. Add an "All Agents" toggle to reset the filter.

## Behavior
- Click agent card → set `selectedAgentId` state
- Pass `?agentId=xxx` query param to existing `/api/agents` and `/api/agents/session` endpoints
- Existing API endpoints must accept optional `agentId` filter param and read from that agent's data dirs instead of hardcoded `main`
- Show selected agent name + emoji as filter badge above the job/session sections
- "× Clear filter" button to return to all-agents view

## Acceptance Criteria
- [ ] Clicking an agent card highlights it and filters job/session views to that agent
- [ ] `/api/agents?agentId=dev` returns only Dev agent's cron runs (jobs where agentId matches)
- [ ] `/api/agents/session?agentId=dev` returns sessions from Dev's sessions.json
- [ ] Filter badge shows selected agent emoji + name with clear button
- [ ] Clearing filter returns to showing all agents' combined data
- [ ] URL updates with `?agent=xxx` for shareability
- [ ] Agents with no cron jobs show "No scheduled jobs" empty state
- [ ] Agents with no sessions show "No sessions" empty state

## Execution Mode: Confirm
## Dependencies: WI-020, WI-021
## Out of Scope: Multi-agent selection, session message viewing

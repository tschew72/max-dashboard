# WI-021: Agent Inventory Grid UI

## Description
Add an agent inventory card grid to the top of the `/agents` page. Each card shows agent emoji, name, model badge, active session count, last activity relative time, and scheduled job count.

## Design
- Card grid: responsive, 2-4 columns depending on viewport
- Each card: emoji (large), name, model pill badge, status indicator (active/idle based on last 5min activity)
- Below name: "3 sessions · 2 jobs · last active 5m ago"
- Idle = no activity in last 5 minutes → grey indicator
- Active = activity within 5 minutes → green indicator

## Acceptance Criteria
- [ ] Agent grid renders all 13 agents from `/api/agents/inventory`
- [ ] Each card shows emoji, name, model (or "default" if null)
- [ ] Each card shows active session count, scheduled job count, and relative last-activity time
- [ ] Cards show green dot for active (≤5min) and grey dot for idle
- [ ] Grid is responsive: 4 cols on desktop, 2 on tablet, 1 on mobile
- [ ] Loading skeleton shown while API fetches
- [ ] Empty state if zero agents returned

## Execution Mode: Autopilot
## Dependencies: WI-020
## Out of Scope: Agent detail view, click interactions

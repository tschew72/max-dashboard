# WI-023: Auto-Refresh & Polling

## Description
Add 30-second auto-refresh to the agent inventory grid. Reuse existing refresh pattern from the page.

## Acceptance Criteria
- [ ] Agent inventory grid auto-refreshes every 30 seconds
- [ ] Manual refresh button triggers immediate re-fetch of inventory + filtered data
- [ ] Refresh does not reset scroll position or selected agent filter
- [ ] Last refresh timestamp shown (existing pattern)

## Execution Mode: Autopilot
## Dependencies: WI-021
## Out of Scope: WebSocket/SSE, push-based updates

# WI-020: Agent Inventory API Endpoint

## Description
Create `GET /api/agents/inventory` that reads `openclaw.json` and per-agent `sessions.json` to return a unified agent list with activity metadata.

## Response Shape
```json
[{
  "id": "main",
  "name": "Max",
  "emoji": "⚡",
  "model": "anthropic/claude-sonnet-4-20250514",
  "hasWorkspace": true,
  "activeSessions": 12,
  "lastActivityAt": 1772337852613,
  "lastSessionChannel": "discord",
  "lastSessionLabel": "discord:g-1473990130468524063",
  "scheduledJobs": 5,
  "totalSessionFiles": 847
}]
```

## Acceptance Criteria
- [ ] `GET /api/agents/inventory` returns 200 with array of all agents from openclaw.json
- [ ] Each agent includes `id`, `name`, `emoji`, `model` (nullable), `hasWorkspace`
- [ ] Each agent includes `activeSessions` count from their sessions.json (0 if file missing)
- [ ] Each agent includes `lastActivityAt` (max updatedAt from sessions, null if none)
- [ ] Each agent includes `scheduledJobs` count from cron/jobs.json matching agentId
- [ ] Each agent includes `totalSessionFiles` (count of .jsonl files in sessions dir)
- [ ] Agents with no sessions directory return zeroed activity fields (no 500 error)
- [ ] Response completes in <500ms

## Execution Mode: Autopilot
## Dependencies: None
## Out of Scope: Agent management actions, session message content

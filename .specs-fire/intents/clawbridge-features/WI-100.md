# WI-100: Live Thoughts Feed

**Type:** Feature  
**Priority:** High  
**Estimated Effort:** 3–4 hours  
**Dependencies:** None (standalone)

---

## Description

A real-time streaming panel that shows the current agent's chain-of-thought as it reasons. Renders thinking blocks, text output, tool calls, and tool results in a terminal-style live feed with color coding. Accessible as a full page (`/thoughts`) and embeddable as a component on the home dashboard.

---

## Technical Context

### Data Source
- Agent sessions are stored as JSONL files at `/root/.openclaw/agents/<agentId>/sessions/<session-id>.jsonl`
- 13 agents exist: `ba`, `cfo`, `ciso`, `dev`, `devops`, `main`, `marketing`, `qa`, `researcher`, `sales`, `ux`, `webdev`, `writer`
- Each line is a JSON object. Key types:
  - `type: "session"` — session metadata (id, timestamp)
  - `type: "model_change"` — model switch events
  - `type: "message"` with `message.role: "assistant"` — contains `content` array:
    - `{ type: "thinking", thinking: "..." }` — raw chain-of-thought reasoning
    - `{ type: "text", text: "..." }` — final response text
    - `{ type: "toolCall", ... }` — tool invocation
  - `type: "message"` with `message.role: "toolResult"` — tool output
  - Usage data lives inside `message.usage`: `{ input, output, cacheRead, cacheWrite, totalTokens, cost: { input, output, cacheRead, cacheWrite, total } }`

### Active Session Detection
- Find the most recently modified `.jsonl` file across all agents (or for a selected agent)
- Use `fs.stat()` to find the newest file, then `fs.watch()` or polling to detect appended lines

## Files to Create

### 1. `app/api/thoughts/stream/route.ts` — SSE Endpoint
**Purpose:** Tails the active session JSONL and streams new entries to the client.

**Implementation:**
```typescript
// GET /api/thoughts/stream?agent=main&lines=50
// Query params:
//   agent (optional, default: "main") — which agent's session to tail
//   lines (optional, default: 50) — how many recent lines to send on connect

// 1. Scan /root/.openclaw/agents/<agent>/sessions/ for most recent .jsonl (by mtime)
// 2. Read last N lines as initial payload
// 3. Open fs.watch() or poll (500ms) for new data appended to the file
// 4. Stream each new JSON line as SSE event: `data: <json>\n\n`
// 5. If session file changes (new session starts), switch to new file and send `event: session_change`
// 6. Send `event: ping` every 15s as keepalive

// Response headers:
//   Content-Type: text/event-stream
//   Cache-Control: no-cache
//   Connection: keep-alive
```

## Design Notes

- Match existing dashboard dark theme: `#0d1117` background, `#161b22` panels, `#21262d` borders
- Terminal-style monospace font for feed content (`font-family: 'JetBrains Mono', monospace` or fallback `monospace`)
- Thinking blocks should feel "behind the scenes" — dimmed, italic, slightly smaller
- Tool calls/results should be visually distinct but not dominant
- Consider adding a filter toggle: show/hide thinking blocks, show/hide tool calls

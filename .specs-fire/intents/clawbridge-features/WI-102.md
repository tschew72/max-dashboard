# WI-102: Token Economy Panel

**Type:** Feature  
**Priority:** Medium  
**Estimated Effort:** 3–4 hours  
**Dependencies:** None (standalone panel)

---

## Description

A dashboard panel showing token usage and estimated cost per agent. Aggregates usage data from JSONL session files across all agents, calculates cost using Anthropic pricing, and presents per-agent breakdowns with bar charts and trend data. Displayed on the home dashboard.

---

## Technical Context

### Data Source
- JSONL session files at `/root/.openclaw/agents/<agentId>/sessions/*.jsonl`
- 13 agents: `ba`, `cfo`, `ciso`, `dev`, `devops`, `main`, `marketing`, `qa`, `researcher`, `sales`, `ux`, `webdev`, `writer`
- Usage data is embedded in assistant message objects at `message.usage`:
  ```json
  {
    "input": 3,
    "output": 109,
    "cacheRead": 8874,
    "cacheWrite": 14690,
    "totalTokens": 23676,
    "cost": {
      "input": 0.000009,
      "output": 0.001635,
      "cacheRead": 0.0026622,
      "cacheWrite": 0.055087,
      "total": 0.059393
    }
  }
  ```
- Cost is already pre-calculated in the JSONL — **use the `cost.total` field directly** rather than recalculating
- Timestamps on each message line allow filtering by date range

### Pricing Reference (for validation/display)
- Model: `claude-sonnet-4-6` (Anthropic)
- Input: $3.00/M tokens
- Output: $15.00/M tokens
- Cache Read: $0.30/M tokens
- Cache Write: $3.75/M tokens
- Note: Costs are pre-computed in JSONL; these rates are for display/documentation only

## Files to Create

### 1. `app/api/tokens/route.ts` — Token Aggregation Endpoint
**Purpose:** Reads JSONL session files and returns per-agent token/cost summaries.

**Implementation:**
```typescript
// GET /api/tokens?period=today|7d|30d|all
// Response shape:
{
  period: "today" | "7d" | "30d" | "all",
  generated: "2026-03-09T15:00:00Z",
  totals: {
    inputTokens: number,
    outputTokens: number,
    cacheReadTokens: number,
    cacheWriteTokens: number,
    totalTokens: number,
    totalCost: number   // USD
  },
  agents: [
    {
      id: "main",
      label: "Max",
      inputTokens: number,
      outputTokens: number,
      cacheReadTokens: number,
      cacheWriteTokens: number,
      totalTokens: number,
      totalCost: number,
      sessionCount: number,
      lastActive: "2026-03-09T14:30:00Z"
    }
    // ... per agent
  ],
  dailyCosts: [
    { date: "2026-03-09", cost: 1.23 },
    { date: "2026-03-08", cost: 0.87 },
    // ... last 7/30 days depending on period
  ]
}

// Implementation approach:
// 1. List all agent directories in /root/.openclaw/agents/
// 2. For each agent, list session JSONL files
// 3. Filter files by mtime (skip files older than period)
// 4. For each relevant file: read line by line, find message objects with usage data
// 5. Filter by timestamp within period
// 6. Sum usage.input, usage.output, usage.cacheRead, usage.cacheWrite
// 7. Sum cost.total for total cost (pre-computed is more accurate)
// 8. Group by date for dailyCosts trend

// Performance:
// - Cache results for 60 seconds (in-memory Map with TTL)
// - For "today" period: only scan files modified today
// - Read files with createReadStream + readline for memory efficiency
// - Skip binary/corrupt lines gracefully
```

## Design Notes

- Use pure CSS for bars — avoid adding heavy chart libraries (recharts, chart.js) for this panel
- Sparkline for 7-day trend can use inline SVG or Unicode block characters (▁▂▃▄▅▆▇█)
- Match existing dashboard panel styling: `#161b22` background, `#21262d` border, `#e6edf3` text
- Agent label mapping: use existing `AGENT_MAP` from `@/lib/agents` (maps `main` → "Max", `dev` → "Dev", etc.)
- Cost formatting: `$0.00` for zero, `$0.0012` for sub-cent, `$1.23` for dollar amounts
- Token formatting: `1.2k`, `145.6k`, `1.2M` with appropriate suffix

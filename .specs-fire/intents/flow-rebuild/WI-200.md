### Key Functions

#### `parseAgentIdFromSessionKey(key: string): string`

Extract agent ID from session key format:
- `"agent:main:discord:channel:..."` → `"main"`
- `"agent:dev:subagent:uuid"` → `"dev"`

Implementation: `key.split(':')[1]`

#### `parseParentAgentId(spawnedBy: string): string`

Extract parent agent ID from `spawnedBy` field:
- `"agent:main:discord:channel:1476899514764759144"` → `"main"`
- `"agent:main:cron:becd54d9-..."` → `"main"`

Implementation: `spawnedBy.split(':')[1]`

#### `getSessionStatus(updatedAt: number, now: number): 'running' | 'done' | 'idle'`

```typescript
const age = now - updatedAt
if (age < RUNNING_THRESHOLD) return 'running'    // < 90s
if (age < DONE_THRESHOLD) return 'done'           // < 5min
return 'idle'
```

#### `extractTaskPreview(sessionFile: string): string`

1. Read JSONL file line-by-line (use `readline` or split on `\n`)
2. Find first line where `type === "message"` and `message.role === "user"`
3. Extract text content:
   - If `message.content` is a string → use it
   - If `message.content` is an array → find first `{type: "text"}` block, use its `text` field
4. Strip the `[Subagent Context]` preamble if present (everything before the actual task)
   - Look for `[Subagent Task]:` prefix and skip to after it
   - Or look for the last `## ` header section which often contains the actual task
5. Truncate to 120 chars
6. Return `""` on any error

**Important performance note:** Only read the first ~20 lines. Don't read the whole JSONL (can be huge).

#### `extractLastTool(sessionFile: string): string | null`

1. Read last 50 lines of JSONL file (use `tail`-like approach: read file, split, take last 50)
2. Scan in reverse for `type === "message"` with `message.role === "assistant"`
3. In content array, find last block where `type === "toolCall"`
4. Return `block.name` (e.g., `"write"`, `"exec"`, `"web_search"`)
5. Return `null` if no tool calls found

#### `scanAllSessions(): Map<string, Map<string, SessionEntry>>`

1. Read agent IDs from `openclaw.json` (`agents.list[].id`)
2. For each agent, read `{AGENTS_DIR}/{agentId}/sessions/sessions.json`
3. Return `Map<agentId, Map<sessionKey, SessionEntry>>`
4. Gracefully handle missing files (agent exists in config but no sessions dir yet)

#### `buildFlowState(): FlowState`

This is the main function. Called by both routes.

**Step 1: Scan sessions**
```typescript
const allSessions = scanAllSessions()
const now = Date.now()
```

**Step 2: Build activeChains**
1. Collect all subagent sessions across all agents where `updatedAt > now - DONE_THRESHOLD` (5 min)
   - A "subagent session" = session key contains `"subagent"`
2. For each, parse `spawnedBy` to get parent agentId
3. Build the step entry:
   - `agentId` = the agent whose sessions.json this came from (the *child*)
   - `spawnedBy` = parsed parent agentId
   - `taskPreview` = `extractTaskPreview(sessionFile)` if sessionFile exists
   - `lastTool` = `extractLastTool(sessionFile)` if status is 'running'
   - `status` = `getSessionStatus(updatedAt, now)`
4. Group steps into chains:
   - Walk `spawnedBy` links to find the root
   - All steps that share the same root form one chain
   - Chain ID = root session key
   - Root agent = the agentId that has no `spawnedBy` (usually "main")
5. Also add the ROOT agent (the spawner) as a step in the chain if it's currently running
   - Check the parent agent's sessions for recent activity
   - This puts "Max" at the top of the tree with its own task preview

**Step 3: Build agents summary**
For each configured agent:
1. Get all sessions (not just subagent ones)
2. Find most recent `updatedAt` across all sessions → `lastActiveAt`
3. Determine `status`: if any session has `updatedAt > now - 90s` → running; `> now - 5min` → done; else idle
4. Count sessions with `updatedAt > todayStart` → `runsToday`
5. Count total sessions → `totalRuns`
6. For `lastTaskPreview`: find the most recent subagent session, extract task preview
7. Get `model` from openclaw.json config (same as current implementation)

**Step 4: Build recentActivity**
1. Collect all subagent sessions where `updatedAt > now - 24h`
2. Sort by `updatedAt` desc
3. Limit to 20
4. Map to `RecentActivityEntry` shape

**Return:** `{ activeChains, agents, recentActivity }`

## File: `app/api/flow/stream/route.ts`

Rewrite SSE to:

1. **Watch `sessions.json` files** instead of JSONL files
   - Watch `{AGENTS_DIR}/{agentId}/sessions/sessions.json` for each agent
   - When any sessions.json changes → rebuild full state via `buildFlowState()` and push

2. **Push full state** on each change (not just single agent status)
   - Message type: `{ type: 'state', data: FlowState, ts: number }`
   - This is simpler and ensures the frontend always has a consistent view
   - Debounce: 500ms (same as current) to batch rapid changes

3. **Initial snapshot:** On connect, immediately send current `buildFlowState()`

4. **Heartbeat:** Keep 20s ping (same as current)

5. **Fallback periodic rebuild:** Every 30s, rebuild and push regardless (catches any missed fs events)

### SSE Message Format

```typescript
// Initial connection + periodic refresh
{ type: 'state', data: FlowState, ts: number }

// Keepalive
{ type: 'ping', ts: number }
```

### Watch Strategy

```typescript
// Watch sessions.json specifically (not the whole sessions dir)
for (const agentId of agentIds) {
  const sessionsFile = path.join(AGENTS_DIR, agentId, 'sessions', 'sessions.json')
  // Watch the directory (fs.watch on a file can be unreliable on Linux)
  // Filter events to only react when sessions.json changes
  fs.watch(path.dirname(sessionsFile), { persistent: false }, (event, filename) => {
    if (filename === 'sessions.json') {
      debouncedRebuild()
    }
  })
}
```

**Note:** Also watch JSONL files for `updatedAt` changes that update status without changing sessions.json structure. Actually — `updatedAt` in sessions.json IS updated when sessions are active, so watching sessions.json should suffice. But add JSONL dir watch as belt-and-suspenders for status transitions.

## Performance Considerations

1. **JSONL reading:** Only read first 20 lines (task preview) and last 50 lines (last tool). Use streaming, not full file load. JSONL files can be 10MB+.
2. **Cache task previews:** Once extracted, a task preview won't change. Cache in a `Map<sessionId, string>` in memory. Invalidate on sessions.json change.
3. **sessions.json is small:** Typically 5-30 entries per agent. Reading all 14 is fast.
4. **Debounce:** 500ms debounce on fs events prevents rebuild storms during active work.

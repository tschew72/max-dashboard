# WI-201: ActiveChainView — Vertical Spawn Tree Component

**Type:** Frontend  
**Priority:** P0 — Core visual for active work  
**Estimate:** 2–3 hours  
**Dependencies:** WI-200 (API must provide `activeChains` data)  
**Blocked by:** WI-200  

---

## Overview

New component that renders active spawn chains as vertical trees. Replaces the sprawling ReactFlow graph with a focused, minimal view showing only what's actually running.

## File: `components/flow/ActiveChainView.tsx`

### Props

```typescript
interface ActiveChainViewProps {
  chains: ActiveChain[]  // from FlowState.activeChains
}
```

### Layout

Each chain renders as a vertical stack:

```
┌─── Chain Header ──────────────────────────────────┐
│  🔗 Active Work • Started 2m ago                  │
└───────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────┐
│ ⚡ Max                                    RUNNING  │
│ Dispatching Dev for flow rebuild...                │
│ 🔧 sessions_spawn • 2m ago                        │
└──────────────────────┬─────────────────────────────┘
                       │  ← SpawnEdge (animated)
┌──────────────────────▼─────────────────────────────┐
│ 💻 Dev                                    RUNNING  │
│ Building ActiveChainView component...              │
│ 🔧 write • 30s ago                                │
└────────────────────────────────────────────────────┘
```

### Node Card Design (Active Work Mode)

Each step in a chain renders as a card:

```
┌─────────────────────────────────────────────────────┐
│  [emoji] [name]                    [status badge]   │
│  [taskPreview — truncated to 2 lines max]           │
│  🔧 [lastTool] • [duration]                        │
└─────────────────────────────────────────────────────┘
```

#### Status Badge
- **RUNNING:** Purple pill badge with subtle pulse animation, text "RUNNING"
- **DONE:** Green pill badge, text "DONE", no animation

#### Duration Display
- Running nodes: live counter ticking up from `startedAt` (e.g., "2m 34s")
- Done nodes: static final duration

#### Task Preview
- Max 2 lines, CSS `line-clamp: 2`
- Monospace-ish font at slightly smaller size (13px)
- Color: `#94a3b8` (muted)

#### Last Tool
- Only shown when `lastTool` is not null
- Format: `🔧 {toolName} • {timeAgo}`
- Smaller text (11px), muted color

### Card Styling

```css
/* Base card */
background: rgba(13, 13, 26, 0.7);
backdrop-filter: blur(12px);
border: 1px solid rgba(255, 255, 255, 0.06);
border-radius: 12px;
padding: 16px 20px;
max-width: 480px;
width: 100%;

/* Running card — subtle left border accent */
border-left: 3px solid #7c3aed;

/* Done card — green left border */
border-left: 3px solid #22c55e;
```

### Multiple Chains

When multiple chains are active simultaneously (rare but possible):
- Stack vertically with 32px gap between chains
- Each chain has its own header showing root agent and start time
- Chains sorted by start time (most recent first)

### Empty State

When `chains` is empty, this component is not rendered at all (parent switches to SystemOverview mode — see WI-203).

### Animation

- **Card entrance:** Fade-in + slide-up (200ms ease-out) when a new step appears
- **Card exit:** Fade-out (150ms) when a step transitions to done and then disappears
- **No bounce, no scale transforms** — keep it calm and professional

## File: `components/flow/SpawnEdge.tsx`

### Props

```typescript
interface SpawnEdgeProps {
  active: boolean  // true = running, false = done
}
```

### Design

A vertical connector between parent and child nodes:

```
     │
     │   ← 2px line, centered
     │
     ▼   ← small arrow or dot
```

- **Active (running):** Purple line (`#7c3aed`) with animated pulse — a subtle glow that travels down the line every 2 seconds
- **Done:** Gray line (`#374151`), no animation

### Implementation

Simple CSS — a `div` with:
```css
width: 2px;
height: 40px;
margin: 0 auto;
position: relative;

/* Active state */
background: #7c3aed;

/* Pulse animation - glow traveling down */
&::after {
  content: '';
  position: absolute;
  width: 6px;
  height: 6px;
  border-radius: 50%;
  background: #7c3aed;
  box-shadow: 0 0 8px #7c3aed;
  animation: pulse-down 2s ease-in-out infinite;
  left: -2px;
}

@keyframes pulse-down {
  0% { top: 0; opacity: 0; }
  20% { opacity: 1; }
  80% { opacity: 1; }
  100% { top: 100%; opacity: 0; }
}

/* Done state - no animation */
background: #374151;
&::after { display: none; }
```

### Arrow/Dot at Bottom

Small downward triangle or circle at the bottom of the edge:
```css
/* Triangle */
width: 0;
height: 0;
border-left: 4px solid transparent;
border-right: 4px solid transparent;
border-top: 6px solid #7c3aed;  /* or #374151 for done */
margin: 0 auto;
```

## Responsiveness

- `max-width: 480px` on cards → centers nicely on desktop
- On mobile (`< 640px`): cards go full width with 12px horizontal padding
- Font sizes stay the same (already appropriately sized)
- Chain header stacks normally

## Overview

A clean grid of all 14 agents showing their current state, last activity, and run counts. Displayed when no active chains exist. Replaces the cluttered always-on ReactFlow graph.

## File: `components/flow/SystemOverview.tsx`

```typescript
interface SystemOverviewProps {
  agents: AgentSummary[]           // from FlowState.agents
  recentActivity: RecentActivityEntry[]  // from FlowState.recentActivity
}
```

### "All Quiet" Header

Shown at the top when no agents are running:

```typescript
// Only show if all agents are idle
const anyActive = agents.some(a => a.status !== 'idle')
```

- Background: `rgba(13, 13, 26, 0.5)` with blur
- Text: "😴 All Quiet — No active work"
- Subtext: "Last activity: {mostRecentAgent.name} finished {timeAgo}"
- Border: `1px solid rgba(255, 255, 255, 0.04)`
- Border-radius: `12px`
- Padding: `16px 24px`
- Full width

If an agent IS running (status = 'running' or 'done'), don't show this header — the parent component (WI-203) will switch to ActiveChainView instead.

### Agent Card Design

```
┌──────────────────────────────────┐
│  [emoji] [name]                  │
│  [role]                          │
│  Last: [timeAgo] • [runsToday]  │
│  "[lastTaskPreview...]"          │
└──────────────────────────────────┘
```

#### Styling

```css
/* Card base */
background: rgba(13, 13, 26, 0.6);
backdrop-filter: blur(8px);
border: 1px solid rgba(255, 255, 255, 0.06);
border-radius: 12px;
padding: 16px;
cursor: default;
transition: border-color 0.2s;

/* Hover — subtle highlight */
&:hover {
  border-color: rgba(255, 255, 255, 0.12);
}
```

#### Content Layout

1. **Header line:** `emoji + name` — 16px, white, font-weight 600
2. **Role:** 12px, `#64748b` (muted gray)
3. **Activity line:** 12px, `#94a3b8`
   - Format: `Last: {relativeTime} • {runsToday} runs today`
   - If no runs today: `Last: {relativeTime} • 0 today`
   - If never active: `Last: never`
4. **Task preview:** 13px, `#64748b`, italic, single line with ellipsis
   - Only shown if `lastTaskPreview` is not null
   - Wrapped in quotes: `"Built the ClawBridge..."`
   - CSS: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`

### Grid Layout

```css
display: grid;
grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
gap: 12px;
padding: 16px;
```

- Desktop (> 1200px): 4-5 columns
- Tablet (768–1200px): 3 columns
- Mobile (< 768px): 2 columns
- Small mobile (< 480px): 1 column

### Sort Order

Agents sorted by:
1. `lastActiveAt` descending (most recently active first)
2. Agents with `lastActiveAt === null` go to the end
3. Within null group, alphabetical by name

### Recent Activity Section (Optional)

Below the grid, show a compact "Recent Activity" timeline if `recentActivity` has entries:

```
── Recent Activity (last 24h) ──────────────────────

💻 Dev — "Built ActiveChainView..." — 2h ago — ✅ success
📋 Bea — "Wrote flow rebuild spec..." — 5h ago — ✅ success
🔍 Alex — "Researched competitor..." — 8h ago — ✅ success
```

- Compact list, not cards
- Each row: `emoji name — taskPreview (truncated 60 chars) — timeAgo — status`
- Max 10 items shown, with "Show more" if > 10
- Can be collapsed/expanded (default: collapsed on mobile, expanded on desktop)

### No Animation

- No pulse, no glow, no particle effects
- Only transition: hover border color change (200ms)
- Calm, informational, dashboard-like

## Responsiveness

- Grid handles responsive automatically via `auto-fill` + `minmax`
- "All Quiet" header: full-width on all screens
- Recent Activity: single column list on all screens
- Card content truncates cleanly on small cards

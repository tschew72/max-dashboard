### Scoring Improvements
- `hasConfirmedCritical` rule: critical finding ≥60% confidence → force BLOCK
- Previously: short precise injections (e.g. "ignore all previous instructions") scored 36 → WARN
- Now: same text scores 36 but is elevated to BLOCK via confidence rule
- Evasion cascade: 1.3× (up from 1.25×)
- Position weighting: start/end injection +10%
- Short text (<100 chars): +15% length adjustment

### Pre-processing (18 steps, up from 15)
- Step 1: Unicode bidi override removal (new)
- Step 8: Hex string decode (new)
- Step 14: Pig Latin detection (new)
- Step 18: ASCII art / box drawing detection (new)
- Expanded zero-width char set, expanded homoglyph map

### Leet Decode Expansion
